OVERVIEW
--------
Mobile-first React landing page template with SEO optimization, light/dark themes,
and performance-focused architecture.

================================================================================
SEO OPTIMIZATIONS
================================================================================
• Dynamic meta tags (description, keywords, Open Graph, Twitter Cards)
• JSON-LD structured data (Local Business schema)
• Semantic HTML5 with proper heading hierarchy (H1-H3)
• Keyword-rich content with natural integration
• Descriptive alt text for all images (50-125 chars)
• robots.txt + sitemap.xml configuration
• Canonical URLs to prevent duplicate content
• Mobile-first indexing ready

================================================================================
PERFORMANCE FEATURES
================================================================================
• Native lazy loading for images (loading="lazy")
• Async image decoding (decoding="async")
• Critical image preloading for above-the-fold content
• Code splitting with manual vendor chunks
• Terser minification for production builds
• Tree shaking for unused code elimination
• LCP (Largest Contentful Paint) monitoring
• Performance.mark() tracking for Core Web Vitals
• Estimated Lighthouse score: 95+/100

================================================================================
RESPONSIVE DESIGN
================================================================================
• Mobile-first CSS with progressive enhancement
• Fluid typography using clamp() (responsive font sizes)
• Responsive breakpoints: 640px, 768px, 1024px, 1280px
• CSS Grid for complex layouts, Flexbox for components
• Touch-friendly tap targets (minimum 44x44px)
• Mobile-optimized slide-out navigation menu
• Container-responsive wrapper with max-widths

================================================================================
LIGHT/DARK THEME SYSTEM
================================================================================
• CSS Custom Properties (variables) for theme values
• Automatic system preference detection (prefers-color-scheme)
• Persistent theme storage in localStorage
• Smooth theme transitions (0.3s ease)
• Theme toggle button with ARIA labels
• No FOUC (Flash of Unstyled Content)
• WCAG 2.1 AA contrast ratios

================================================================================
FUNCTIONALITY
================================================================================
• Sticky header with backdrop blur and scroll detection
• Smooth scrolling with Lenis library
• Mobile hamburger menu with slide animation
• Skip to main content link for accessibility
• Controlled form components with validation
• Responsive image gallery grid
• Multiple call-to-action buttons with scroll to contact
• Accessible ARIA labels on all interactive elements
